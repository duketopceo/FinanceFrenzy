# Legacy Python Implementation

This directory contains the original Python/PyQt6 implementation of Finance Frenzy.

## Files

- **app.py** - Main application entry point
- **assets.py** - Asset management dialog
- **liabilities.py** - Liability management dialog
- **stock_exchange.py** - Stock exchange trading interface
- **cashflows.py** - Cashflow tracking dialog
- **game_over.py** - Game over screen
- **ui.py** - UI utilities

## Running the Original Python Version

To run the original Python implementation:

1. Install Python 3.8+
2. Install dependencies:
   ```bash
   pip install PyQt6 pandas
   ```
3. Run the application:
   ```bash
   python app.py
   ```

## Note

This implementation is preserved for reference purposes. The new Unreal Engine 5 version provides enhanced graphics, performance, and cross-platform support.
